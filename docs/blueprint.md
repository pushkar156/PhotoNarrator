# **App Name**: Photo Narrator

## Core Features:

- Photo Upload: Upload a photo via drag and drop or file selection.
- AI Paragraph Generation: Use Gemini API to analyze the photo and generate a detailed, descriptive paragraph. The AI acts as a tool, choosing whether or not to include identified objects or aspects in its writing.
- Paragraph Display: Display the generated paragraph beneath the uploaded photo.
- Copy to Clipboard: Provide an option to copy the generated paragraph to the clipboard.
- Regenerate Description: Offer a button to 'Regenerate' the description if the user is not satisfied, creating a new paragraph from the same image.

## Style Guidelines:

- Primary color: Forest green (#386641), evoking nature and observation.
- Background color: Very light green (#F2F7F2), a calm backdrop.
- Accent color: Soft brown (#A68A5A), for a touch of earthiness in the details.
- Font: 'Literata', a serif for readability and a literary feel.
- Simple, clear icons for upload, copy, and regenerate functions.
- Clean and modern layout with the photo prominently displayed above the generated description.
- Subtle loading animation while the AI generates the description.
